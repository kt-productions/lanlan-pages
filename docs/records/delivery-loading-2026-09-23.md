# 已交稿委託按需載入驗收

日期：2026-09-23。使用者確認調整委託管理及公開進度，並要求載入按鈕放在已交稿 section 內。

## 行為

- 開啟或重新載入只要求未交稿資料；GAS 在分頁之前篩選，不是下載全部再隱藏。
- 已交稿欄顯示「未載入」及「載入已交稿」按鈕；選取已交稿階段不自動下載。按下後只下載已交稿範圍，再合併到目前快照。
- 搜尋提示目前範圍；補載失敗保留原資料並可重試。重新載入恢復未交稿，完成及封存資料均保留。
- 未補載時，管理員將委託改為已交稿會關閉編輯視窗並移出目前清單；補載後仍可查看及改回其他階段。

## 驗證

- 93 項離線測試通過，新增交稿範圍在分頁前套用、舊 completed 對應、封存隔離、管理權限、跨頁完整性、補載去重及錯誤範圍拒絕案例。
- 建置、產物檢查及修改的 JavaScript 語法檢查通過。
- Chrome 桌機可用頁面 1905 × 855 與手機 390 × 844 視窗，以私人本機虛構資料驗證預設未交稿、欄內載入、鍵盤 Enter、失敗重試、階段／封存篩選、搜尋、重新載入、改為已交稿及改回排隊。手機實際頁面寬度與可用視窗寬度一致，無整頁橫向溢出。
- 本機 API 請求記錄確認初次只有 active、補載只有 delivered；已交稿按鈕移到 section 後重新驗證。管理端補載後保留編輯入口，未見瀏覽器應用程式錯誤。
