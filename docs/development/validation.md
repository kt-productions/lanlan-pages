# 驗證指南

此文件提供檢查方法與涵蓋範圍。依 [AGENTS.md](../../AGENTS.md) 選擇與變更直接相關的檢查；實際執行結果分開保存，見[歷史紀錄](../records/verification-2026-09-22.md)。

## 現有檢查指令與實際涵蓋範圍

所有指令在 LanLan Pages 根目錄執行。依 `AGENTS.md` 選擇與變更直接相關的項目，文件修改不必全部執行。

| 指令 | 目前涵蓋範圍與限制 |
| --- | --- |
| `npm run build` | 重新產生 `dist/`、四頁 HTML、共用導覽、靜態資源、404、robots 與 sitemap；不啟動伺服器。 |
| `npm run check` | 需先建置；檢查作品 ID、分類與精選引用、影片／縮圖存在及大小界線、媒體數值、連結 HTTPS 格式、模板替換、四頁資源／縮圖／錨點、重複 DOM ID、舊表單入口移除、影片屬性、50 筆表單素材大小／SHA-256、款式圖片及價格，以及 `assets/site/` 的靜態 import 和 JS／CSS 來源一致性。 |
| `npm test` | 先打包 Apps Script，再執行 `tests/*.test.mjs`：計價邊界與明細、未知選項、第 3 版草稿／跨類型空值、10／100 MB 與 MIME 限制、聯絡網址，以及來源解析、跳脫、模板缺值和路徑界線；另測收件冪等、通知失敗、權限、版本衝突、公開欄位及 RSA 簽章；不啟動服務，不代替瀏覽器或真實部署驗收。 |
| `node --check <檔案路徑>` | 對實際修改的 JavaScript／`.mjs` 做語法檢查，不執行頁面互動。 |
| `npm run dev` | 先建置再啟動本機預覽，須遵守 `AGENTS.md` 的啟動授權。 |
| `npm run preview` | 只提供既有 `dist/`，須先自行建置並具備啟動授權。 |

`npm run check` 不會播放影片、確認外部連結可達、重算首頁原始圖片雜湊，或驗證前端即時狀態與後端上傳。模組檢查針對目前採用的靜態 import；若日後新增動態 import、CSS 外部資源或其他載入方式，須同步擴充。檢查腳本存在不等於本次已執行。

影片原始檔及兩種衍生版會核對 SHA-256、大小、比例、片長及 MP4 快速起播索引；`npm run optimize:videos` 另以 ffprobe 驗證影格數、影格率與音軌保留。瀏覽器需驗證只有可見影片下載預覽版、點開才請求展示版；方法見[影片壓縮](video-optimization.md)。

## 介面驗收重點

依改動範圍檢查，並記錄實際瀏覽器尺寸與結果；以下是驗收範圍，不代表已驗收通過。

- 作品分類、每次多載入 6 件、全頁播放選擇、減少動態、自動播放受阻、影片錯誤、檢視器與焦點還原。
- `/lanlan-pages/` 與根路徑資源、四頁直接開啟／重新整理、首頁與委託頁導覽、手機選單及無 JavaScript 後備內容。
- 貼圖三頁選取、跨頁全選／取消與半選、折扣級距、No.33–35 特殊折扣、商用與付款切換。
- 角色動畫／小動圖單雙人切換、逐位複雜費、轉場開關、不適用欄位停用，以及畫面、確認頁、草稿的金額一致性。
- 暱稱與聯絡必填、繁中提示／焦點／錯誤欄位關聯、Facebook URL、授權預設未選、檔案空值／類型／大小界線、切換類型重新驗證、返回修改與第 3 版草稿下載。單元測試已涵蓋 10／100 MB 邊界；真實瀏覽器大型檔案與後端上傳需另外測試，不能混為一談。
- 桌機說明欄 sticky、展開後恢復頁面流、手機固定金額列、鍵盤焦點、橫向溢出與主控台錯誤。可沿用 1280×720／390×844 作起點，涉及斷點時另檢查 760px 及 440px 附近。

## 委託服務驗收

- 離線替身驗證送件與重試、後台編輯／衝突／通知重試／登出；公開看板涵蓋七階段、急件／擱置並存與解除、篩選後分頁、全部／空結果／失敗重試及私人欄位排除。旗標切換不得改價，擱置不得清除工作階段。
- 管理看板讀完所有分頁後顯示完整件數，搜尋可命中後續頁；三類型／階段／旗標／空結果、卡片編輯視窗、儲存後移欄、關閉與 Escape 焦點還原、未儲存確認、還原、失敗／衝突保留輸入、登入到期清空及手機捲動。公開卡片不得重新出現「訂單資訊」展開區。結果見[管理看板與編輯視窗](../records/admin-board-2026-09-23.md)。
- Sheet 升級驗證 27／29／30 欄舊版只追加缺少表頭、不改資料；目前合併 Trello 來源後共 31 欄。尾端占用或公式時拒絕。舊狀態讀取不回寫，首次修改保留原值與歷史；未知狀態明確回報。
- Trello 匯入：同名不同 ID、封存、排序、未知欄位停止、整批驗證、重跑不覆蓋、未知報價／授權、通知 0 次、公開名稱白名單、完整件數與分頁，使用虛構測試資料。
- 真實部署後依[服務設定](order-service.md)驗證匿名 Google 存取、CORS、OIDC、白名單及通知目的地；不能把替身結果記為平台驗收。

## 文件整理的檢查

純文件變更檢查 Markdown 結構、本機連結、專案路徑、npm 指令與實作是否一致。搬移文件時，同步更新 README、文件導覽、AGENTS.md 及跨文件引用；區分保留的歷史數字與目前規格，避免搬移時遺漏內容。

在 Git 倉庫中檢視 `git status --short`、`git diff` 與 `git diff --check`；有暫存內容時另檢查暫存差異。尚未初始化 Git 時，保留修改前副本，使用 `git diff --no-index` 及空白檢查比較，不為文件檢查初始化倉庫。
