# 管理看板與編輯視窗驗收

日期：2026-09-23。依使用者需求，公開進度移除「訂單資訊」，管理頁改為相同外觀的七欄看板，卡片新增編輯入口，原編輯功能移入彈跳視窗。

## 變更範圍

- 公開卡片保留類型、原公開名稱或匿名編號、急件／擱置、封存註記及公開說明；移除展開區與時間明細。來源資料及 API 時間欄位沒有刪除。
- 管理頁依序取得所有 30 筆分頁，核對總數後顯示完整看板。搜尋及類型／階段／旗標篩選涵蓋完整快照；讀取失敗不取代先前快照。
- 編輯視窗保留三類委託欄位、預估、工作階段、旗標、備註、通知重試、修改歷史及 Trello 來源／時間／附件。儲存後卡片立即更新位置。
- HTML dialog 提供固定標題與操作鈕、內容捲動、Escape、焦點還原及未儲存修改確認，取代瀏覽器原生 confirm。GAS 第 6 版、登入權限、Sheets 與收件設定沒有更動。

## 本機驗證

使用專案外、僅綁定 loopback 的隔離測試服務與 71 筆虛構資料；管理操作使用既有 Apps Script 測試替身及業務邏輯。此環境不連線正式服務、不傳送 Telegram 訊息，測試資料及伺服器不進入 Git 或網站產物。

Chrome 實際尺寸為桌機 1280×900、手機 390×844：

修正驗收時發現的兩處問題：手機單欄規則原被後方樣式覆蓋；重開視窗時瀏覽器可能還原上次聚焦欄位的捲動位置。已調整 CSS 順序，並在開啟後重設內容捲動，再以手機尺寸確認。

`node --check` 通過全部 8 個本次新增／修改的 JavaScript 檔案；`npm test` 67 項通過（含同時完成的影片測試）。新增 3 項管理資料測試涵蓋完整分頁、後續頁搜尋、讀取失敗／筆數變動、循環游標與重複缺漏。整合建置後 `npm run build`、`npm run check` 通過。
