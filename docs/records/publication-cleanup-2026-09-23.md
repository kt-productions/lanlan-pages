# 2026-09-23 公開前整理

依使用者要求整理公開 GitHub 前的內容：私人雲端資源另行管理，提交者信箱允許公開，文件不保存個人電腦資訊，移除未開放及未使用素材，補齊忽略規則。沒有建立提交、推送、發布網站或變更雲端資源。

## 完成內容

- 雲端設定紀錄移除 Drive 資料夾、訂單 Sheet、GAS 編輯專案的真實管理連結及 Script ID；另存專案外私人維運清單。公開 API URL 原樣保留，`.clasp.json` 仍被忽略。
- 移除文件中的個人帳號目錄、絕對工作路徑、暫存備份位置與個人插件安裝快照。clasp 範例改用維護者自行提供的環境變數。
- 未開放款式與未使用素材共 16 個檔案、159,902,586 bytes，已移出專案封存。同步整理素材來源清單、款式資料及公開來源節錄；原始資料完整保存在專案外副本。
- `.gitignore` 補上 clasp 憑證、金鑰、私人維運設定、備份與訂單／草稿匯出規則；公開範例和正常來源仍可加入 Git。
- 保留既有提交者身分。價格、草稿第 3 版契約、現有作品及公開 API 設定未變。
