# 驗證指南

依 [AGENTS.md](../../AGENTS.md) 與[後續決策對照](current-state.md)選擇直接相關的檢查。此頁記錄方法，實際結果另放[歷史紀錄](../records/README.md)；有測試腳本不代表本次已執行。

## 指令與涵蓋範圍

所有指令在專案根目錄執行。純文件修改檢查連結、指令、現行規格與差異，不必啟動預覽。

| 指令 | 涵蓋範圍與限制 |
| --- | --- |
| `npm run build` | 產生五頁 HTML、收益檢視共用來源、導覽、靜態資源、轉址頁、404、robots、sitemap、release.json；不啟動服務。 |
| `npm run check` | 須先建置；核對素材清單、影片原檔／衍生檔及受管作品雜湊、表單素材、DOM ID、資源／模組／錨點、模板與產物一致性。 |
| `npm test` | 先打包 GAS，再跑 `tests/*.test.mjs`；涵蓋計價、草稿、驗證、登入與競態、收件／通知／附件、看板、報價／收益、作品流程、Git 發布及後端打包白名單。使用虛構資料，不連線正式服務。 |
| `npm run test:media` | 以 ffmpeg／ffprobe 實際處理 PNG、JPG、GIF、MP4，驗證來源保留、衍生媒體與清單；不部署。工具路徑見[開發指南](setup.md)。 |
| `node --check <檔案路徑>` | 檢查修改過的 JavaScript／mjs 語法；GAS 另由打包測試解析與測試環境執行。 |
| `npm run build:backend` | 驗證共用模組轉為 GAS 的打包流程；產物不放入網站 dist。 |
| `npm run dev`／`npm run preview` | 有授權後提供本機瀏覽器驗收；後者不會建置。 |
| `git diff --check` | 空白及差異檢查；另讀 status、實際 diff，有暫存變更時亦檢查 cached diff。 |

靜態檢查不會播放影片、測試外部連結可達或證明 Google／Telegram 權限正確。影片壓縮工具另以 ffprobe 核對影格與音軌，見[影片維護](video-optimization.md)。不以單元測試代替瀏覽器、真實登入或正式部署驗收。

## 頁面、導覽與作品集

- 根路徑與 `/lanlan-pages/`：五頁直接開啟、重新整理、舊 HTML 轉址、收益 query 檢視、資源及站內連結。
- 桌機及手機：頁面有內容、標題正確、主控台沒有相關錯誤、沒有整頁橫向溢出；手機選單、鍵盤、可見焦點及無 JavaScript 後備內容可用。依變更檢查 760px、440px 等斷點。
- 作品分類、小動圖每批 8 件／其他分類 6 件、載入更多、放大、上一件／下一件、關閉焦點及快速切換。
- 背景影片只在可見且允許動畫時載入；檢視器開啟才下載展示版。驗證暫停／恢復、媒體失敗、自動播放受阻、減少動態及省流量偏好。
- 三個管理入口共用狀態：未登入、格式損壞與到期時隱藏；未到期的保存登入先顯示，再背景驗證。網路中斷不閃爍，明確失效才隱藏；跨分頁登出或到期後，晚回應不能恢復入口或資料。
- 作品與收益的登入回程只接受固定本站目的地。確認本機儲存被封鎖、彈出視窗受阻、取消、票證過期、重試及重新整理行為。

## 委託表單與管理

- 三種類型、三步驟、必填提示／焦點、Facebook 網址、授權預設未選、不適用欄位停用及切換後重驗。
- 貼圖跨頁全選／取消／半選、數量與特殊折扣；單雙人、複雜費、轉場、商用及付款選擇。畫面、確認頁及第 4 版草稿共用計價。
- 每檔 10 MiB、最多五檔、合計 45 MiB、MIME／檔頭／雜湊、檔案與連結至少一項。虛構檔案逐檔上傳，回應中斷保持原 requestId 與快照，不能重複建單。
- 公開六階段、急件／擱置、暱稱與核可來源名稱、封存排除；管理預設小動圖、直接點卡片／鍵盤編輯、拖曳成功後才移欄。拖曳尾隨點擊不得誤開視窗。
- 看板讀完所選交稿範圍才呈現；已交稿按需補載。搜尋及篩選提示目前範圍，失敗保留快照，不把未載入當成零件。
- 編輯與還原、未儲存確認、Escape／關閉焦點、版本衝突保留輸入、登出清空、附件預覽及 Object URL 釋放。
- 三類型報價明細、負折扣、小數、零元、空值、總額上限；Trello 只編輯總額，清除保留歷史，舊頁／拖曳不清掉金額。收益另驗證跨月／跨年、三類互斥、缺值、完整快照及保存後重讀。
- Sheet 升級：已知 27／29／30／31 欄只追加到 32 欄，表頭或整欄占用／公式停止；訂單、來源、revision 與歷史保留。
- Trello 匯入：同名不同 ID、封存、排序、整批驗證、重跑不覆蓋、不推定金額／授權、不發送通知。
- 完整文字與圖片／文件通知：每位、每段及每組回執保存；只補未確認成功項目，結果不明時不宣稱未送出。

## 作品服務與發布

- 新增、只改文字、換檔、下架、保存草稿與直接發布；沒有發布確認勾選，但後端仍核對權限、版本、原檔保存及清理條件。
- 上傳中斷接續、工作重試、併發衝突、非目前工作版本拒絕；未保存的失敗工作可按條件放棄。
- Drive 父目錄／應用程式標記／原檔大小與雜湊；main 保存核對成功才清理該次暫存，清理失敗可重試，不刪除原始 Git 歷史。
- production 只快轉、不強制覆蓋；相同 SHA 重試、分歧停止、過期部署略過、release.json 及部署回報核對。
- 離線模擬與真實 App push、GAS 權限、Google 結果回程是不同驗收範圍。正式流程見[作品服務](artwork-service.md)，過去 PNG 實測及其他格式限制見[流程紀錄](../records/artwork-flow-2026-09-24.md)。

## 文件與程式碼核對

先記錄原有未提交變更；不得把別人的修改恢復或混入無關回退。文件檢查標題層級、相對連結及錨點、npm 指令、環境變數、模組路徑、頁面數、資料欄位與 workflow 分支是否符合實作。未變更的歷史證據保留日期及當時數字。

程式碼檢查各層責任、共用計價與契約、管理權限入口、資料白名單、DOM 文字呈現、來源及 Object URL 生命週期、例外提示、必要業務註解與除錯殘留。統一一般來源的 UTF-8／LF、兩格縮排、檔尾換行與可讀排版；不改寫原始表單存檔或第三方來源。

純排版可比對修改前後 JavaScript 語法樹，再跑語法、打包及對應互動回歸。格式檢查不能證明沒有行為問題，仍須檢視實際 diff；後端打包與 clasp 白名單應由測試核對完整性。

## 結果記錄

紀錄放在 `docs/records/`，檔名含日期，並加入[索引](../records/README.md)。寫明工作樹或提交範圍、實際指令、瀏覽器尺寸、資料是否為虛構、結果與未驗證部分，不把歷史測試當成本次結果。

截圖、暫存腳本、下載檔及完整日誌放專案外；公開文件不包含私人路徑、憑證或真實委託。若需要變更雲端資料、發布或傳送真實通知，先依既有授權界線處理。
