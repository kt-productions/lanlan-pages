## 影片與作品檢視

- 94 支作品影片加上首屏重複展示的 3 支，共產生 97 個首頁影片元素；素材仍是 94 支，不是 97 件獨立作品。
- 影片預先顯示縮圖，透過 `data-src` 延後載入。具備 `IntersectionObserver` 時，只在影片進入可視範圍、未隱藏且允許播放時載入與播放；不支援時採既有後備判定。
- 兩處全頁播放控制共用狀態。切換分類、載入更多及關閉檢視器不重設暫停選擇；離開畫面、隱藏分頁或開啟檢視器時暫停背景影片。
- 預設靜音、循環、行內播放。`prefers-reduced-motion` 為 reduce 時初始暫停，訪客仍可手動開啟；CSS 同時停用動態過場與平滑捲動。
- 自動播放受阻時提供手動提示，媒體失敗顯示錯誤文字。檢視器有原生影片控制、上一件／下一件、Escape、左右方向鍵與焦點還原；影片控制取得焦點時保留其方向鍵行為。
- 檢視器依目前分類瀏覽，不在首尾循環。Ctrl／Command 等修飾鍵點選仍可開啟原始檔；無 JavaScript 時保留全部作品、介紹及價目，隱藏無法操作的分類控制，手機導覽直接顯示連結；表單顯示需啟用 JavaScript 的提示。

## 委託表單與預估呈現

初始類型為角色動畫，步驟依序為「委託內容、聯絡與設定、確認內容」。直播與作品展示授權不預選；條件欄位依類型隱藏並停用，切換類型會回到第一步、清除閱讀確認及已產生的確認快照，其他輸入可能保留供切回使用。

必填及格式錯誤使用本站繁中提示，將焦點移到第一個錯誤控制，以 `aria-invalid` 與 `aria-describedby` 關聯提示。切換類型時會立即重驗保留的參考檔，無效檔案不繼續顯示有效縮圖；離開頁面釋放 Object URL，從瀏覽器往返快取恢復時重建預覽。

桌機左側說明與預估欄為 sticky，距頂端 24px；展開「委託說明與製作流程」時改為一般頁面流，不限制高度或建立內部捲軸。760px 以下改單欄，左側取消 sticky；底部固定金額列提供「查看明細」入口，頁面保留底部及安全區域空間。

角色動畫與小動圖有單人／雙人選擇，逐位列出複雜費；角色動畫另有加購轉場。貼圖分成三頁，每頁 16 款，支援跨頁全選／取消與半選狀態，並標示數量折扣級距。所選款式的「原價小計」與折扣後預估是不同數值。

2026-09-23 依使用者指定，在第一步的貼圖包款式選項前加入 `sticker-discounts.png`，在小動圖方案選項前加入 `chibi-03.png`。圖片與各自的類型欄位一起顯示／隱藏，採完整比例、最大寬度不超過表單，提供替代文字與另開原圖連結；角色動畫不顯示這兩張圖。素材對應見[素材來源](../reference/assets.md)。

預估欄、手機金額列、確認頁及草稿使用同一個 `estimateCommission()` 結果。轉場及複雜費的上下限是尚待繪師確認的需求範圍；PayPal、急件與折扣順序已依目前規則確定，不再描述為來源衝突待解。完整規則見[表單與計價規格](../reference/commission.md)，資料欄位見[草稿契約](../reference/draft-schema.md)。
