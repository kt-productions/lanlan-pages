# 開啟正式委託收件

日期：2026-09-23。使用者在管理看板驗收後明確要求「幫我開啟收件」。

- 在既有 GAS 專案的指令碼屬性，僅將 `ACCEPTING_ORDERS` 從字串 `false` 改為 `true`，按儲存後重新載入設定頁，確認仍為 `true`。
- 沿用 Web App 第 6 版。`Orders.gs` 每次新送件讀取此屬性，因此本次不需重新部署 GAS 或修改前端程式。
- 正式 [委託表單](https://kt-productions.github.io/lanlan-pages/commission/) 可正常開啟，顯示「填寫需求・確認後送出」；前端提示取決於 API 是否設定，收件開關仍以後端已儲存屬性為準。
- 本次驗證設定持久化及表單入口，沒有新增訂單、送出表單或傳送 Telegram 測試通知。先前完整功能結果見[後台驗收](admin-2026-09-23.md)及[新版管理看板](admin-board-2026-09-23.md)。
- 若需暫停新收件，將同一屬性改回字串 `false`；既有訂單、公開進度及管理功能保持可用。不要刪除屬性、重建試算表或清除歷史。

本次僅更新雲端設定與維護文件；文件相對連結、差異及空白檢查通過，未因文件變更重跑程式測試。
