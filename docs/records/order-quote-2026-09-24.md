# 管理訂單金額與明細驗收 — 2026-09-24

依使用者需求，一般訂單提供金額明細編輯與自動加總，Trello 歷史訂單只提供總金額。此功能放在既有管理卡片的編輯視窗，不增加付款或通知流程。

## 實作與資料保留

- `src/features/orders/quote-editor.js` 提供預估明細、設定／清除金額、增減明細及即時加總；範圍項目不自動認定最低價。
- `contract.js` 由前後端共用，以整數分驗證金額；手動報價另存 `detailsJson.quote`，保留系統預估、來源及修改歷史。省略報價時保留原值，拖曳與舊管理分頁不會清除。
- 沿用 32 欄 Orders、管理員權限、revision、ScriptLock 與歷史快照；不需執行資料遷移。正式發布需先更新 GAS 的 Core，再由 GitHub Pages 發布前端。

## 實際驗證

- 120 項 Node.js 測試通過，涵蓋三種服務的報價存取、折扣、小數、零元、無效金額、總額邊界、歷史保留、舊頁／拖曳相容、Trello 限制、權限與版本衝突。修改的 JavaScript 語法及正式網址建置、產物檢查通過。
- 使用已授權、只綁定 `127.0.0.1` 的虛構資料服務。桌機 1280 × 900、手機 390 × 844，實測小動圖明細由 1,200 + 150.25 − 50.25 加總為 NT$ 1,300，儲存後重新整理讀回一致，原預估仍為 NT$ 1,200 ~ 1,400。
- 空白範圍金額阻止儲存並聚焦欄位；新增／移除更新合計，移除後關閉會出現放棄修改確認。Trello 只顯示總額，NT$ 888.88 儲存後在手機重新開啟一致。
- 模擬版本衝突保留輸入；兩種手機金額版面沒有水平溢出，瀏覽器無相關警告或錯誤。測試未修改正式委託或傳送真實通知。
- 貼圖包兩款 NT$ 400、角色動畫 NT$ 4,700 也完成介面儲存；取消勾選並儲存後恢復尚未設定，登出後清空明細與預估內容。表單草稿仍為第 4 版，未改收件費率。

正式環境採來源及部署版本核對、靜態產物比對與唯讀檢查；不以真實訂單試寫金額。

GAS 已發布第 16 版，發布前核對第 15 版來源並保存回復副本；只有 Core 變更，固定版本內容與本機產物一致，Web App 網址不變。前端沿用 `main` 推送觸發既有 GitHub Pages 流程。
