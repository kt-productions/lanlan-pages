# 完整 Telegram 委託通知驗收

2026-09-23 依使用者要求，將表單填寫與選擇內容一併傳至原 Telegram 通知名單；已部署 GAS 第 10 版，沿用 Web App 網址、收件設定、權限與 32 欄 Orders。

## 通知內容與重試

- 文字包含暱稱、聯絡平台與方式、參考連結與檔名、款式／方案／人數／轉場／背景／急件、商用、付款、直播與範例授權、閱讀確認、特殊需求、預估金額與計價明細、報價說明、委託編號與後台入口。只列適用的選項，未詢問的商用與直播顯示「此表單未詢問」。預估沿用伺服器計價，不新增價格規則。
- 先傳完整純文字，最多 4096 字元一段，長文保留所有內容、段次與委託編號，不解析使用者 HTML／Markdown。五張靜態圖片仍使用一組相簿，首張簡短說明；沒有拆成五則個別圖片。
- 固定通知名單及一份文字快照；逐位保存文字段落與附件結果。重試沿用原快照，只補未成功部分；不明結果不自動重送。舊版已成功的委託不補寄。沒有刪除或批次改寫既有訂單。

## 驗證結果

- `npm test`：89 項通過，包含三類完整欄位、否與未詢問、48 款、2000 字元連結、4000 字元需求、表情符號、20 位收件人、伺服器金額、文字失敗補送、修改期間快照固定及公開資料隔離。
- 五圖相簿與文字回執分開；文字失敗而相簿成功後，重試只傳文字。既有相簿失敗、多人重試、通知鎖、管理員同期修改及收件冪等測試維持通過。
- 修改的 JavaScript／GAS 語法、`npm run build`、`npm run check` 與 Git 差異檢查通過。
- 正式 GAS 擁有者環境使用同版通知函式、虛構填單內容及既有五張測試圖片，Telegram 回覆一則完整文字與一組五張圖片傳送成功；文字回傳內容逐字一致，五張圖片具有同一相簿識別碼。原測試單逐欄一致，沒有新增訂單或修改通知紀錄；臨時擁有者測試入口已移除，沒有新增公開 API。

本次修改僅涉及後端通知，未變更網站畫面；未重做表單瀏覽器流程或 Telegram 客戶端的人工閱讀驗收。正式驗證依 Telegram API 回傳確認傳送，不代表收件人已閱讀。私人來源備份與部署紀錄保存於專案外。
