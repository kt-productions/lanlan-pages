# 委託表單與計價規格

規格核對日期：2026-09-22。依 `content/commission.json`、`src/pages/commission/index.html`、`src/pages/commission/index.js` 與 `src/features/commission/pricing.js` 整理目前規則；原表單及交付條款另見[來源存檔](source-forms.md)。

站內表單提供即時預估、草稿下載及可設定的正式送件；未設定 API 時不開放收件。以下記錄現行欄位、計價與決策差異；只有取得後端回執才代表已收件，下載草稿不會加入排單，預估不是正式報價。

## 目前欄位與適用類型

除特殊需求與本機參考檔外，顯示於所選類型的下列填答欄位皆必填。初始類型為角色動畫；直播與作品展示授權均不預選。

| 欄位 | 貼圖包 | 角色動畫 | 小動圖 |
| --- | --- | --- | --- |
| 暱稱、聯絡平台、聯絡方式 | 有 | 有 | 有 |
| 本機參考檔（選填） | 單一圖片，10 MB | 單一檔案，100 MB，可 ZIP | 單一檔案，100 MB，可 ZIP |
| 參考素材連結（送件必填） | HTTPS 連結 | HTTPS 連結 | HTTPS 連結 |
| 款式／方案 | 01–48 款多選，至少一款 | 由角色與加減價選項描述 | 插圖／插圖＋動畫 |
| 角色人數 | 無 | 單人／雙人 | 單人／雙人 |
| 循環動畫加購轉場 | 無 | 是／否 | 無 |
| 複雜費 | 特殊需求另行報價，未自動計入 | 按人數自動顯示每位 0–2,000 範圍，不是填答欄位 | 按人數自動顯示每位 0–200 範圍，不是填答欄位 |
| 商業用途 | 是／否 | 是／否 | 無；計價不另加商用費 |
| 背景與特效 | 無 | 需要／單色或無背景 | 無 |
| 急件 | 無，不接受急單 | 是／否 | 是／否 |
| 付款方式 | 轉帳／匯款或 PayPal | 轉帳／匯款或 PayPal | 轉帳／匯款或 PayPal |
| 直播繪製同意 | 是／否 | 是／否 | 無 |
| 作為作品範例同意 | 是／否 | 是／否 | 是／否 |
| 特殊需求 | 選填，需註明款式 | 選填，可說明動作、格式或匿名需求 | 無；後續聯絡討論 |
| 已閱讀委託說明 | 必須勾選 | 必須勾選 | 必須勾選 |

聯絡平台限 Telegram、Facebook、Discord。暱稱最多 80 字元、聯絡方式最多 300 字元、特殊需求最多 4,000 字元；暱稱與聯絡方式不得全是空白。Facebook 會檢查 HTTPS 及 `facebook.com`（含子網域）或 `fb.me` 網域；Telegram／Discord 目前只檢查非空白與長度，不確認帳號是否存在。

本機參考檔改為選填，正式送件必填 HTTPS 素材連結；選檔不會上傳。已選檔案不能為空，大小檢查使用 `referenceLimitMB × 1024 × 1024` bytes。貼圖要求 MIME 以 `image/` 開頭；角色動畫及小動圖不限制類型。PNG、JPEG、GIF、WebP、AVIF 可嘗試本機圖片預覽，其他檔案只顯示中繼資料；可選取的類型不等於都能顯示縮圖。10／100 MB 是前端限制，尚未驗證任何後端上傳能力。

貼圖每頁 16 款，共三頁；全選／取消涵蓋全部 48 款，部分選取顯示半選狀態。切換類型會隱藏並停用不適用欄位，回到第一步並清除閱讀確認與確認快照；不保證清除所有已輸入內容。保留的參考檔會立即依新類型重驗大小與 MIME，無效時顯示原因並隱藏預覽。草稿中的不適用值另見[資料契約](draft-schema.md)。

2026-09-23 新增第一步說明圖片：貼圖包在款式選項前顯示數量折扣圖 `sticker-discounts.png`；小動圖在方案選項前顯示交付格式圖 `chibi-03.png`。兩者均取自 `public/assets/forms/`，只隨對應類型顯示，可另開原圖閱讀；圖片不是填答欄位，也不加入草稿或計價資料。

`src/features/commission/validation.js` 維護本機欄位檢查及繁中錯誤文字，`reference.js` 管理圖片預覽與 Object URL 釋放。價格與檔案限制的動態提示取自設定；固定選項文字、規則敘述及此文件仍需隨費率變更同步核對。

## 目前計價規則

計價設定以 `content/commission.json` 的各服務 `pricing` 為準，款式價格由建置時解析 `content/forms/sticker-options.json` 的 `label`；金額計算集中在 `src/features/commission/pricing.js`。首頁 `content/site.json` 的展示價目是獨立文字，不是計價函式輸入。

| 規則 | 貼圖包 | 角色動畫 | 小動圖 |
| --- | --- | --- | --- |
| 基本價 | 各款 NT$50–250，按選取加總 | 單人 4,500 | 插圖 NT$600；插圖＋動畫 NT$1,200 |
| 第二角色 | 不適用 | +3,000 | 所選方案原價 +50%：插圖 +300，含動畫 +600 |
| 複雜費 | 未計入，另行報價 | 每位 +0–2,000 | 每位 +0–200 |
| 加購轉場 | 不適用 | +500–1,000 | 不適用 |
| 商用 | 折扣後總價 ×2 | +1,000 | 不另加價 |
| 單色／無背景 | 不適用 | -1,500 | 不適用 |
| 急件 | 不適用 | +2,500 | 固定 +600 |
| PayPal | 完整加減價後小計 +5% | 完整加減價後小計 +5% | 完整加減價後小計 +5% |
| 幣別 | `TWD` | `null`，僅顯示「元」，不自行指定為新台幣 | `TWD` |

貼圖數量滿 12／24／36／48 張分別折 100／250／400／600，只取達標最高級距、不累加。No.33–35 中選取的第 2、3 款半價，可與數量折扣併用；不是任意款式都能享有半價。計算順序是款式原價加總 → 扣除數量與特殊款折扣 → 套用商用倍數 → 加 PayPal 5%。

全選 48 款原價 7,400，扣除 600 + 200 後，一般用途 6,600、商用 13,200；使用 PayPal 時分別為 6,930、13,860。兩種折扣分開列於明細。

角色人數最多兩人，複雜費逐位加總；小動圖第二角色的 50% 只乘方案原價，不放大急件或複雜費。預估上下限分別計算，金額以整數分處理，PayPal 加價四捨五入至小數兩位。PayPal 5% 是本站委託加價設定，不代表官方收款費率。

角色動畫單人、無其他加減價、轉帳時目前預估為 4,500–6,500；小動圖單人插圖為 NT$600–800，含動畫為 NT$1,200–1,400。上限來自自動納入的複雜費，不是已確認的固定報價；轉場與特殊需求仍由繪師確認。未完成必要選項時仍可能顯示暫估範圍，需完成填答才能進入確認頁。

已確認決策保存在 `content/commission.json` 的 `updates`；原始文字不回寫為新費率。開放委託狀態、排隊時間與正式交期均須另外確認。
