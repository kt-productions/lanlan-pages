## 視覺對照與限制

參考 Trello 的橫向階段欄、件數、堆疊卡片與欄內捲動；沿用本站金棕配色、系統繁中字體及原導覽。採公開唯讀看板，狀態透過管理頁修改，沒有公開拖曳改單。手機保留可左右捲動的欄寬，避免把七欄縮成難讀的窄格。訂單資訊可展開，沒有把未提供的交期或報價塞入卡片。

仍觀察到 GAS 偶發 45 秒讀取逾時；成功請求能返回完整資料，瀏覽器會提示失敗並可重試。曾以不含 charset 的外部探測收到平台 HTML，改用與前端相同的 UTF-8 Content-Type 後完整 API 驗證通過；不能據此斷言所有逾時原因已排除。這次不是持續同步，後續 Trello 異動不會自動更新本站。
