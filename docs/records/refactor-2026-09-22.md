互動修正包括：手機無 JavaScript 時保留導覽連結、隱藏無效分類控制；手機選單支援外部點擊收合及斷點切換；必填提示固定使用繁中並關聯錯誤控制；切換類型立即重新驗證參考檔；圖片預覽失敗或離開頁面時釋放 Object URL，往返快取恢復時重建。計價對未知類型明確拒絕，未知小動圖方案維持待選範圍，避免產生非數字金額。

原始內容、作品、費率及草稿第 2 版欄位不變。原始來源文字不因在地化或目前價格規則而改寫。AGENTS 的目錄、驗證範圍與風格說明依此次使用者要求同步；預覽、發布、素材保留及送件限制仍適用。
