# 有效管理登入的導覽入口

日期：2026-09-24。依使用者要求，首頁、委託表單、委託進度與委託管理的 `main-nav` 在本站 Telegram 登入仍有效、並通過後端管理白名單確認後顯示「委託管理」。桌機與手機共用相同行為。

## 實作

- 建置預設隱藏入口；`admin-access.js` 呼叫 `auth.session` 驗證後才顯示。後端沿用既有驗證，不讀取訂單、不傳回 Telegram 身分、不延長登入期限。
- 登入交換或管理 API 成功可立即確認本頁入口；各頁功能與導覽共用 API client，避免重建 GAS 通訊 iframe。
- 登出、到期及權限失效隱藏入口；跨分頁登入資料變更同步驗證，回到頁面或恢復連線時重驗。網路失敗暫時隱藏但保留憑證；延遲回應不得恢復已登出的入口。
- 原三天期限、管理 API 權限、訂單與通知規則不變。頁尾維持沒有管理入口。

## 同日補充：改善已登入的入口顯示速度

使用者回報每次換頁仍需等待入口。原因是先前實作把顯示綁在 GAS 通訊建立與 `auth.session` 回覆之後。現改為依已保存、未到期的登入紀錄立即顯示，再背景驗證；重驗及暫時網路失敗不隱藏入口。登出、到期、AUTH／FORBIDDEN 仍隱藏與清除，舊請求不能恢復已登出的入口。僅改變連結呈現，沒有放寬管理資料或操作的後端權限，也不延長三天期限。

本機 1280 × 900 對照測試刻意暫停驗證回覆：舊版須等手動釋放（約 10.3 秒）才顯示；新版首頁約 125 毫秒已顯示，當時後端仍未回覆。另次首頁為 280 毫秒，進度頁 75 毫秒、管理頁 69 毫秒；委託表單亦在回覆前顯示。這些為隔離環境的單次觀察，不是正式網路延遲保證。

390 × 844 手機選單在背景等待時可前往管理頁。網路失敗保留入口，權限撤銷後隱藏、跨分頁登出及延遲回應不恢復、等待中到期仍隱藏均已驗收。桌機與手機截圖已檢視，主控台無警告或錯誤。126 項測試、修改檔案語法檢查、正式網址建置與產物檢查通過；沒有修改真實訂單、發送通知或更新 GAS。
