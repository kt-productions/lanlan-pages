# 2026-09-23 公開工作進度看板

依使用者更正，進度頁讓所有人瀏覽所有工作，不再要求委託編號查詢。採七個工作階段，額外標記急件／擱置。這次更新本機來源、網站與 Apps Script 打包產物，沒有上傳雲端、升級真實 Sheet、部署或傳送 Telegram 通知。

## 變更與資料相容

- 階段為排隊中、草稿繪製中、草稿確認、等待付款、完稿中、待付尾款、已交稿。取消百分比及單筆可見性控制，保留工作識別編號；送件後連到完整看板。
- `isRush`、`isOnHold` 可並存、各自解除；擱置不清除階段，急件標記不修改 `details.rush` 或報價。後台儲存沿用權限、revision、歷史與重新計價驗證。
- 公開 API 先依完整資料篩選，再依收件時間排序並分頁；每次 30 筆，回傳符合條件總數。清單包含已交稿及舊版隱藏工作，但舊隱藏說明須經管理儲存才公開。固定公開欄位不包含私人資訊。
- 保留原 27 欄，只在尾端安全追加兩個旗標表頭；舊列不直接搬移或清空。舊狀態採讀取相容對應，管理儲存時保留原始狀態及欄位歷史，詳細規則見[服務契約](../reference/order-api.md)。
- `content/commission.json` 及第 3 版草稿格式未變，原有計價與素材保持原狀。
