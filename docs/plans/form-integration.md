# 委託服務後續規劃

2026-09-22 使用者要求開發 Sheets 收件、Telegram 通知、管理員登入、訂單編輯與公開進度，相關程式已實作；後續已建立新的 Sheets 與獨立 GAS，並上傳後端，仍維持暫停收件。雲端進度見[設定紀錄](../records/cloud-setup-2026-09-22.md)，現行操作見[委託服務設定](../development/order-service.md)，資料結構見[服務契約](../reference/order-api.md)。

## 尚待實際環境驗收

- 2026-09-23 已部署 GAS Web App 第 1 版、升級 Orders 為 30 欄，並驗證匿名進度、管理 API 拒絕匿名存取及本機瀏覽器跨來源讀取。維持暫停收件。
- Telegram 憑證、多位通知使用者及管理員數字 ID；以虛構資料測試前須確認測試目的地。bot 沿用 `@KTProductionsBot`。
- 使用者於 2026-09-23 後續已授權 GitHub Pages 發布；正式管理頁網址已確定，後端 `ADMIN_URL` 與 BotFather Allowed URLs 仍待設定。
- 真實 Telegram 登入、通知及手機瀏覽器回程。離線替身不代表上述項目已通過。

2026-09-23 已依使用者更正為公開所有工作的七階段看板，附加急件／擱置標記；不採委託者輸入編號查詢自己的進度。後續 GAS 設定已同步最新程式，雲端操作見[本次設定紀錄](../records/service-setup-2026-09-23.md)。

## 尚未實作

- Drive 私有檔案上傳、格式檢查、權限及保存期限；目前採 HTTPS 素材連結，本機選檔只預覽。
- 自動發送個別進度通知。私人查詢碼／委託者登入不屬於目前公開工作看板需求。
- 正式報價確認、付款與退款；目前仍使用原有預估。
- 更完整的防垃圾提交、歷史封存及大量訂單儲存方案。

角色動畫幣別與確切範圍費用，仍依[委託規格](../reference/commission.md)維護。未開放款式已依使用者公開前整理要求移出專案。後端串接不代表自行決定營運規則；正式發布與真實通知依專案授權規則處理。
