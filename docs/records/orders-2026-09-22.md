# 委託服務實作與驗證紀錄 — 2026-09-22

本紀錄對應 Google Sheets 收件、Telegram 通知、指定管理員登入及編輯、公開匿名進度功能。程式已完成，本次沒有建立或部署真實雲端資源，沒有傳送 Telegram 訊息；`content/integration.json` 仍為空網址，網站預設不收件。

## 實作與決策

- 前端維持原生 HTML、CSS 與 ES Modules，增加 `progress.html`、`admin.html`；主要導覽增加委託進度，管理入口放在頁尾。
- Apps Script 來源放在 `backend/apps-script/`，部署產物獨立放在 `build/apps-script/`，不包含於 `dist/`。設定及維護步驟見[服務設定](../development/order-service.md)，欄位及操作見[API 契約](../reference/order-api.md)。
- 本次採公開匿名進度，僅顯示編號、類型、狀態、百分比、公開說明與更新時間；不公開委託者、聯絡方式、素材或內部備註。管理員可關閉單筆公開顯示。
- 參考素材採 HTTPS 連結，原本的檔案選擇只作本機預覽。草稿升為第 3 版；既有費率、折扣及幣別未變更。
- 伺服器重新驗證與計價，冪等識別碼保護重試；通知失敗不回滾訂單。管理更新比對版本並保留舊內容與操作者；通知狀態更新不覆蓋同期修改。
- Telegram OIDC 驗證使用 RS256、公鑰、PKCE、nonce、單次 state 與原分頁綁定；依 Telegram 數字 ID 判斷管理權限。敏感設定只從 Script Properties 取得。
