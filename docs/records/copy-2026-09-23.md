# 委託頁文案與頁尾驗收

日期：2026-09-23。依使用者指定更新公開介紹、排序提示、表單類型介紹及頁尾入口；設計規格見[介面規格](../design/interface.md)。

- 進度介紹合併為單一段落，移除原先額外的暱稱、Trello、封存與交期說明；件數旁顯示「依照委託順序排列」。排序程式與封存篩選未變更。
- 表單預設顯示角色動畫介紹，切換貼圖包、小動圖及角色動畫後均顯示使用者指定文字。共用 `content/site.json` 的描述，由建置注入前端設定及預設 HTML。
- 四頁共用頁尾移除管理連結；保留著作權、Powered by、社群與品牌連結，管理頁網址及 Telegram 入口未變更。
- `npm run build`、`npm run check` 與修改腳本的語法檢查通過。
- Chrome 本機驗收使用既有虛構資料服務；桌機與 390 × 844 手機視窗均檢查進度介紹、三種類型切換及截圖。手機頁面寬度等於可用視窗寬度，沒有整頁橫向溢出。
- 瀏覽器檢查首頁、委託表單、委託進度與管理頁的頁尾均無管理連結；表單切換及進度讀取未見瀏覽器錯誤或警告。

本次沒有送出正式委託、寫入訂單、發送通知或更新 GAS；本機介面驗收不等同重新驗證後台登入及正式送件流程。
